# Archive Index

This directory contains historical documentation, completed audits, analysis reports, and research documents that provide context and reference for the EIGHTBOL project.

## Organization

### Audits
Comprehensive audits of AST coverage, backend verification, frontend architecture, and error handling.

### Completion Reports
Project status snapshots and completion reports from various implementation phases.

### Analysis Documents
Technical analysis including AST coverage analysis, conformance status, test coverage gaps, and verification indexes.

### Planning Documents
Implementation plans, checklists, and project planning documents.

### Research Documents
Language research studies, implementation research, and interview summaries for various language implementations.

## Navigating the Archive

Each subdirectory contains an INDEX.md file with complete listing and descriptions of its contents.

**For active development**, refer to:
- `doc/PROGRAMMERS-REFERENCE.texi` — Main developer reference
- `doc/EIGHTBOL.texi` — Master TeXinfo documentation
- `README.md` at project root
- `AGENTS.md` — Development guidelines
