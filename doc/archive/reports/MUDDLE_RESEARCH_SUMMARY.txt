MUDDLE LANGUAGE OVERVIEW (1971 MIT Project MAC):

Heritage: MIT Design Language (originally "Muddle")
Created by: Sussman, Hewitt, Reeve, Daniels
Famous use: Zork interactive fiction
Influenced: Scheme, Common Lisp, Prolog, Smalltalk, actor model
Platform: PDP-10, VAX, Apollo/Domain (1971-1980)

Key Features:
- Lisp-like S-expression syntax (prefix notation)
- Multiple data types: lists, strings, arrays, user-defined types
- Lexical scoping (not dynamic)
- Multithreading and coroutines
- Advanced debugging
