# Example: Tavern Greeting Scene with Tier 1 Constructs

This example demonstrates all implemented Tier 1 constructs in action.

## Fountain Source Code

```fountain
INT TAVERN - MAIN ROOM #42#

INNKEEPER has peach skin, brown hair, a blue robe, and head 3.
ENTER INNKEEPER at "Bar Counter".

PLAYER enters at "Door".

Beat.

Cut to center on INNKEEPER.

INNKEEPER
Hello there, traveler! Welcome to The Wandering Griffin.

PLAYER looks interested.

Truck left to include PLAYER.

PLAYER
(to "drink")
I could use a drink.
(to "food")
What's for dinner?
(to "continue")
Just passing through.

Wait for 1 second.

-- FADE OUT --

# Drink Option

INNKEEPER gestures happy right.

INNKEEPER
Ale, mead, or wine?

2 Beats.

Cut to center on PLAYER.

PLAYER looks confused.

PLAYER
What do you recommend?

Dolly up to center on "Barrel Shelf".

-- FADE IN --

INNKEEPER animates pouring.

Beat.

> FINIS.
```

## AST Representation (Simplified)

```lisp
(:program
  :scenes ()
  :statements (
    ;; Scene header
    (:scene :location "TAVERN - MAIN ROOM" :map "TavernMainRoom" :scene-type :normal)
    
    ;; Character entry
    (:character-entry :character "INNKEEPER" :location "Bar Counter" :modifiers (...))
    (:character-entry :character "PLAYER" :location "Door" :modifiers ())
    
    ;; Tier 1: Timing - Beat
    (:timing :type :beat :beats 1)
    
    ;; Tier 1: Camera - Cut
    (:camera :direction :cut :target "INNKEEPER")
    
    ;; Dialogue
    (:dialogue :speaker "INNKEEPER" :text "Hello there, traveler! Welcome to The Wandering Griffin.")
    
    ;; Tier 1: Character Action
    (:character-action :character "PLAYER" :action "looks" :emotion :interested)
    
    ;; Tier 1: Camera - Truck
    (:camera :direction :truck :target "PLAYER")
    
    ;; Tier 1: Dialogue Branching
    (:branch :speaker "PLAYER" :choices (
      (:branch-choice :label "drink" :text "I could use a drink.")
      (:branch-choice :label "food" :text "What's for dinner?")
      (:branch-choice :label :continue :text "Just passing through.")
    ))
    
    ;; Tier 1: Timing - Wait
    (:timing :type :wait :duration 1)
    
    ;; Transitions
    (:transition :type :fade)
    
    ;; ... scene label "Drink Option"
    
    ;; Tier 1: Character Action with emotion and gesture
    (:character-action :character "INNKEEPER" :action "gestures" :emotion :happy :gesture :right)
    
    ;; ... more dialogue and actions
    
    ;; Tier 1: Character Action with animation
    (:character-action :character "INNKEEPER" :action "animates" :animation "pouring")
    
    ;; Tier 1: Timing - Beat (multiple)
    (:timing :type :beat :beats 1)
    
    ;; Tier 1: Camera - Dolly
    (:camera :direction :dolly :location "Barrel Shelf")
    
    ;; More transitions and endings...
  ))
```

## Parsing in Action

Here's what happens during parsing:

1. **Lexer Phase:**
   - Tokenizes "PLAYER looks interested."
   - Recognizes: IDENTIFIER(PLAYER), IDENTIFIER(looks), IDENTIFIER(interested), PERIOD
   - On second pass with keywords: IDENTIFIER(PLAYER), ??? (looks isn't a keyword)
   - Treats "looks" as identifier → action verb candidate

2. **Parser Phase (Character Action Detection):**
   - In `parse-statement()`, encounters IDENTIFIER
   - Calls `parse-character-action()` (backup position prepared)
   - Matches PLAYER + "looks" verb
   - Looks for emotion/gesture/animation
   - Finds :interested emotion keyword
   - Creates `:character-action` node with emotion

3. **Transpiler Phase:**
   - Receives `:character-action` node
   - Extracts: character="PLAYER", action="looks", emotion=:interested
   - Generates: `\ PLAYER looks (interested)`
   - Returns comment node for assembly/Forth compilation
